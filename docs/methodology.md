# Methodology

## Project Approach

GeoMap Visualizer is an educational computational tool.  The methodology is
deliberately simple and transparent, suitable for a second-year undergraduate
student.

---

## 1. Surface Generation

Surfaces are generated by **numerical parametrisation**: a finite grid of
parameter values $(u_i, v_j)$ is mapped to 3-D points using the surface equations.

```
u_values = linspace(u_min, u_max, N)
v_values = linspace(v_min, v_max, N)
U, V = meshgrid(u_values, v_values)
X, Y, Z = surface_equations(U, V)
```

The grid resolution `N` is configurable via `config.py → GRID_POINTS`.

---

## 2. Mapping Application

Each mapping function accepts a single 3-D point (NumPy array of shape `(3,)`)
and returns the corresponding mapped point.  Vectorised batch versions accept
`(N, 3)` arrays for efficiency.

**Cylinder → Circle:**

```python
theta = arctan2(y, x)          # extract angle
x_out = r * cos(theta)
y_out = r * sin(theta)
z_out = 0.0                    # height is discarded
```

**Plane → Cylinder:**

```python
theta = x / radius             # arc-length → angle
x_out = radius * cos(theta)
y_out = radius * sin(theta)
z_out = clip(y, 0, height)     # y becomes height
```

---

## 3. Distance Calculations

All distances are computed with standard NumPy operations:

- **Euclidean**: `numpy.linalg.norm(p - q)`
- **Cylinder geodesic**: closed-form unroll formula (see `mathematical_background.md`)
- **Circle arc**: closed-form angular formula

No numerical integration is used for the geodesics in this project.

---

## 4. Experiment Design

The reproducible experiment follows this protocol:

1. Fix `numpy.random.default_rng(seed=42)`.
2. Sample `N = 20` random point pairs on the source surface.
3. For each pair, apply the selected mapping.
4. Compute Euclidean distances before and after.
5. Record absolute change, relative change, and ratio.
6. Generate a plain-English interpretation from the aggregate statistics.

No data is loaded from external files.  All sample points are generated
programmatically.

---

## 5. Visualisation

Interactive 3-D visualisations use **Plotly graph objects**:

- Surfaces: `plotly.graph_objects.Surface`
- Circles: `plotly.graph_objects.Scatter3d`
- Points: `Scatter3d` with `mode="markers+text"`
- Connecting lines: `Scatter3d` with `mode="lines"`

Side-by-side source/target views use `plotly.subplots.make_subplots`.

---

## 6. Testing

Unit tests are written with **pytest** and cover:

- Output shapes and types
- Known analytical values (e.g. quarter-circle arc = π/2)
- Edge cases (same point, zero distance, invalid input)
- Mathematical properties (symmetry, non-negativity, triangle inequality)

Tests are deterministic and require no external resources.

---

## 7. Limitations of the Methodology

See `limitations.md` for a full discussion.  Key points:

- Geodesics are computed by simplified closed-form formulas, not by solving the
  geodesic ODE numerically.
- Only Euclidean (not geodesic) distances are used in the mapping comparison.
- The "intrinsic distance" values are approximations for educational purposes.
